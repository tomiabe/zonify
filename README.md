# Zonify

World clock and timezone management app — search cities, compare local times, and track the people you work with across time zones.

**Features**

- Search any city or timezone worldwide
- Pin cities to your dashboard with a single click
- Assign people to cities to see their local time at a glance
- Side-by-side time comparison across multiple zones
- Auto light/dark mode based on time of day

## Run Locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev
```
